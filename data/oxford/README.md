# Oxford Battery Degradation Dataset (mirror)

Source: University of Oxford ORA repository
(https://ora.ox.ac.uk/objects/uuid:03ba4b01-cfed-46d3-9b1a-7d4a7bdf6fac),
feature-engineered summary mirrored from a public pipeline and verified
against the dataset's own documented characteristics (8 cells, C1dc
diagnostic-discharge protocol) in oxford_battery_data.py's verify_oxford().

8 independent cells, ~46-78 diagnostic-discharge samples each, used as a
second, independent dataset alongside NASA PCoE — see docs/RESULTS.md
section 10.
